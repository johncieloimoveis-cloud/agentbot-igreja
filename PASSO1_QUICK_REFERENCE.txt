 SHEEPCARE - PASSO 1 QUICK REFERENCE

⚡ VERSÃO RÁPIDA - Execute em sequência:

1. VERIFICAR PRÉ-REQUISITOS:
   $ node --version          (esperado: v18+)
   $ npm --version           (esperado: v9+)

2. ABRIR TERMINAL NA PASTA SHEEPCARE

3. INSTALAR DEPENDÊNCIAS:
   $ npm install

   Aguarde: 30 segundos a 3 minutos
   Resultado esperado: "added 500 packages in 45s"

4. CRIAR ARQUIVO .env.local:

   macOS/Linux:
   $ cp .env.example .env.local

   Windows PowerShell:
   > Copy-Item .env.example .env.local

5. PRONTO! (ainda sem Supabase)

   O arquivo .env.local foi criado com valores placeholder.
   Você preenche com as chaves do Supabase depois (Passo 2).

🔄 SE DEU ERRO:

"npm: command not found"
  → Reinstalar Node.js em https://nodejs.org

"EACCES permission denied" (Mac/Linux)
  → Usar: sudo npm install

"ERESOLVE unable to resolve dependency tree"
  → Usar: npm install --legacy-peer-deps

Terminal travado
  → Pressionar: Ctrl + C
